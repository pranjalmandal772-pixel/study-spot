# Roadmap

## Sprint 1 — MVP
- Define problem and target user
- Create sample study-location dataset
- Build preference inputs
- Build weighted recommendation score
- Display best match and alternatives

## Sprint 2 — User feedback
- Test with 5–10 students
- Ask what factors are missing
- Compare recommendations with users' own choices
- Adjust scoring only when feedback supports it

## Later, only if useful
- Distance/location filter
- Hours and live occupancy
- Saved preferences
- More personalized recommendations

## Prioritization
For the MVP I prioritized features that directly answer: “Where should I study right now?” Features such as accounts and maps were deferred because they add effort without proving the core value first.
